# 一个期望优化问题的完整解法（MDP + 精确有理数最优性证书）

> **问题来源**：《赛尔号》精灵「嘲风」的最后一关（游戏内为每日 6 次挑战机会，两边 boss 各打一遍完成 1 次提升，等价于每日 3 次提升机会）
> **规则**：
> 1. 初始通关概率为 0
> 2. 每天可进行 3 次概率提升，每次提升后通关概率 +2%
> 3. 可随时以当前通关概率尝试通关，尝试次数无限
> 4. 尝试失败则通关概率减半，向下取整
> 5. 求最优期望通关策略
> 一个**单实例 MDP 的端到端求解演示**：问题 → 建模 → 求解 → 证书 → 复现

从初始状态（p=0%，r=3）出发，问题的精确解如下——

最优策略（唯一）：首日两次提升至 4% 尝试，失败提升回 4% 再试，败则收工；此后每日三次提升至 8% 尝试，失败于 4% 再试，败则收工

其期望通关天数：649/73 ≈ 8.89 天（精确有理数，0/400 证书）
